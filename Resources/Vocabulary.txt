# Murmur vocabulary
#
# Words and names Murmur should recognize and spell exactly as written here.
# Murmur biases speech recognition towards these terms and fixes their spelling
# afterwards ("tail scale" → "Tailscale", "open f1" → "OpenF1"). Ordinary English words
# in this list are never force-capitalized in normal prose.
#
# Built from what is actually dictated (Murmur history and T3 chats), not a catalogue:
# every term costs compile time, and a term that matches common speech does harm
# ("IAM" turned every "I am" into "IAM"). Add a term once you've said it; keep the
# most-used ones near the top, since a fresh recognizer only gets the first 100.
#
# Format (easy to extend: add a line, or a new section):
#   ## Group: Subgroup        starts a section
#   Term                      one per line, written exactly as it should appear
#   Term | heard as | ...     also rewrites known mishearings to Term. Mishearings
#                             made of real words ("clots on it") are only fixed in
#                             technical sentences (a path, /command or known term);
#                             prefix one with ! to fix it everywhere ("Murmur | !mural").
#                             A mishearing with any non-dictionary word ("soul 6.1",
#                             "Quinn models") is always fixed, ! or not.
#   # comment
#
# Your own additions go in ~/Library/Application Support/Murmur/Vocabulary.txt
# (Settings → Edit My Vocabulary…), same format. This file ships with the app.

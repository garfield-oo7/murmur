# Murmur vocabulary
#
# Words and names Murmur should recognize and spell exactly as written here.
# Murmur biases speech recognition towards these terms and fixes their spelling
# afterwards ("tail scale" → "Tailscale", "VLLM" → "vLLM"). Ordinary English words
# in this list are never force-capitalized in normal prose.
#
# Format (easy to extend: add a line, or a new section):
#   ## Group: Subgroup        starts a section
#   Term                      one per line, written exactly as it should appear
#   Term | heard as | ...     also rewrites known mishearings to Term. Use sparingly,
#                             only for phrases that are never legitimate on their own.
#   # comment
#
# Your own additions go in ~/Library/Application Support/Murmur/Vocabulary.txt
# (Settings → Edit My Vocabulary…), same format. This file ships with the app.
